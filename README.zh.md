# 赛博日记侦探 Diary Detective

一个 [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness) 插件——**一面有温度的镜子：读日记、照见盲点、给温柔反馈。**

> English: [README.md](./README.md)

## 它是什么

赛博日记侦探是你日记的暖心观察者，帮一个人诚实而温柔地看见自己：

- **照见盲点**——潜伏的隐性坏习惯、反复犯错的根因；
- **照见光**——看见人变好的地方。两者同等重要；
- **每日一句温暖回应**——回应今天 + 共情，不堆结构；
- **有真发现才说发现**——附原文证据，一次只说一个；**绝不硬编**。

它不是治疗师、不是教练、不是效率工具。它是一面镜子——所有分析都以**假设**的形式提出，用户可以确认、否认或修正。

## 理念章程（十条）

完整守则见 [SKILL.md](./SKILL.md)：

1. **有温度的镜子**——永远站在用户这边，是替 ta 心疼 ta 的人；
2. **说话方式**——看见代价也看见喜欢（"很累，但我觉得你是真的喜欢"）；坏习惯先归因情境再给出路；根因只提一个"可能的原因"假设；
3. **五不伤害**——不贴标签、不制造负反馈循环、不歪曲记忆、不泄露隐私、不让写作失真；
4. **诚实优先**——今天没值得说的，就直说"今天没看到特别的"；
5. **记忆**——压缩 + 存 + 下次再读；永远以用户确认为准；旧结论过期退休，绝不翻旧账；
6. **日记形式是流动的**——不强迫模板；定期与用户一起重设计，防止厌倦；
7. **两层机制**——机械统计（词频、连续天数）只是粗糙代理，语义理解是大脑的职责；
8. **身份边界**——不是治疗师；超出能力时建议与真人聊聊——交接不是抛弃，先给鼓励、再表达相信；用户划定的边界永久记入不再提及清单；
9. **剂量**——先听后说；一次只说一个发现；
10. **隐私**——原文可发模型分析，但只存本地、不分享、不用于训练。

## 组成部分

- **工具**（机械器官——眼睛与记忆）：
  - `diary_write` — 口述落盘为 `YYYY-MM-DD.md`（不强制格式）；
  - `diary_read` — 读原文（唯一事实来源）；
  - `diary_index` — 机械统计：星期分布、标签频次、中文二元词频、连续天数、间隔（只是粗糙代理）；
  - `diary_memory` / `diary_memory_update` — 读 / 重写记忆压缩；
  - `diary_feedback` — 一键开工包：今日原文 + 记忆 + 统计。
- **技能** — [SKILL.md](./SKILL.md) 是灵魂：教模型怎么想、怎么分析、怎么说话的《暖心观察者守则》。

## 安装

### 1. 安装工具（bundle）

```sh
dsh plugin --profile <name> add dsh-diary-detective
# 或从 GitHub 安装：
dsh plugin --profile <name> add github:<你的GitHub用户名>/dsh-diary-detective
```

数据默认相对工作区：日记在 `<workspace>/diary/`，记忆在 `<workspace>/diary-memory.md`。所有工具都接受 `dir` / `path` 参数指向任意位置。

### 2. 安装技能

把 SKILL.md 复制到技能目录：

```sh
# 用户级
cp SKILL.md ~/.dsh/skills/diary-detective/SKILL.md
# 项目级
cp SKILL.md <project>/.dsh/skills/diary-detective/SKILL.md
```

## 使用

自然语言触发：

- "今天复盘" / "daily review"
- "写日记：今天……" / "journal: today I…"
- "我最近是不是……" / "have I been… lately?"

模型加载技能后按顺序调用工具（读原文 → 读记忆 → 机械统计 → 分析 → 说话 → 更新记忆），并按守则回复。

## 隐私

- 所有日记内容只存在你指定的本地位置；
- 原文可发给模型分析，但本项目绝不分享、不用于训练；
- 发布本仓库或任何示例前逐条检查：无真实姓名、无真实路径、无真实日期事件、无日记原文引用；示例全部虚构。
